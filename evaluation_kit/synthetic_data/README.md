## 設計對照（每份主檔都埋了 E1–E9）

E1 條件式選擇、E2 觸發→行動→結果、E3 界線／教訓、E4 轉變／矛盾（含自我解釋）、
E5 第一人稱抱怨（官方說法 vs 自身經驗）、E6 想做卻做不到＋土法、E7 訪員重述（排除項）、
E8 純背景敘述（排除項）、E9 跨受訪者對照點。

跨受訪者對照軸：主題 1「對節拍值不值得」（P01 正／P02 條件反／P03 反／S1D 量產反）；
主題 2「數據與運動動力」（S2A 依賴／S2B 依來源劃界／S2C 事後看＋反盯錶／S2D 因數據放棄）；
主題 3「高額遠單接不接」（S3A 條件反／S3B 反／S3C 深夜正／S3D 郊區必接）。

## 使用

```powershell
# 檢核（修改任何逐字稿後必跑；通過才會重寫 CSV 與 SHA256SUMS）
python seal_check_dataset.py --anchors anchors.json --dirs 逐字稿 ..\..\test_kit\逐字稿 --out 埋點對照表.csv

# Part B 執行後收集與自動比對
python ..\seal_eval_collect.py results\ --key 埋點對照表.csv --out collected\
```

粗糙化已包含：贅詞與改口、少量半形標點、2 處講者標籤獨立成行、搶話「——」、指代不清。
依計畫書 §7.1 第 3 步，建議研究者再手動抽改 10–20% 並重跑檢核，然後才凍結。
