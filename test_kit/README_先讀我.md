# 海豹測試包（合成資料）

這裡的訪談內容全部是為了測試工具而寫的虛構腳本，沒有任何真實受訪者。
可以安心放進 repository，也可以直接刪掉重來。

## 檔案

```
研究指引_短影音配樂.txt        ← Open Coding 的「研究指引」欄位要選這個
逐字稿/
  P01_個人創作者.txt           73 句 · 5 區塊
  P02_接案剪輯師.txt           64 句 · 5 區塊
  P03_學生創作者.txt           52 句 · 4 區塊
邊界案例/                      ← 只有在做穩定性測試時才用，平常不要跟上面混在一起跑
  邊界1_講者標籤獨立成行.txt
  邊界2_半形標點.txt
  邊界3_沒有標點的長段落.txt
  邊界4_空白檔案.txt
```

## 三份逐字稿是設計過的

每一份都刻意埋了對應到某條規則的內容，例如「除非要投廣告才買授權」是條件式行為模式、
P01 說對節拍值得花兩小時而 P03 說完全是浪費時間是一組跨受訪者的矛盾、
「他們說系統會提供版權提醒，可是我沒收到」是第一人稱抱怨（舊版會誤判成訪員發言而丟掉）。

完整的對照表與評分方式在評估流程文件裡，照著跑就能給出客觀的分數，
不必憑感覺判斷「這個 code 看起來還可以」。

## 最快的跑法

先只跑 P01 一份，模型選 `qwen3:4b`。確認流程走得通、CSV 打得開之後，
再一次跑三份。第一次跑之前不用自己寫研究指引 —— 上面那份已經寫好了。
